WHY

  the published bench, scripts/distill/bench2.py, times fp16.  The UNet input layout is otherwise the same
  (9 channels: 4 noisy latents + 4 frame latents + 1 mask; pipeline lines ~648-660), so dtype is the main remaining
  difference between the synthetic bench and the deployed path.

  arm is not run and this file is reported as "not triggered".

  exactly ONE changed line (dt is read from env DT in {fp16, bf16}, default fp16); `diff` shows only line 20.
