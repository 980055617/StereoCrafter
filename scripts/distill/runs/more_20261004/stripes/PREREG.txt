  hole pixel  = mask >= 0.5 (the pipeline's own mask_processor binarisation; the mask quadrant is lossy h264).
  crack pixel = hole pixel inside a HORIZONTAL run of hole pixels of length <= 3 in its row.  Longer runs

  Variants (each applied to the warped right-eye frames before VAE encode / CLIP embedding):

    B  telea  / keep    cv2.inpaint(uint8 RGB, crack mask, radius 3, INPAINT_TELEA), per frame
    C  rowlin / shrink  A's fill + mask set to 0 on the filled crack pixels (only runs > 3 px stay masked)
  Fill-free pixels are bit-identical (asserted at runtime: changed_outside_crack_region == 0).
